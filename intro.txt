Create app.py 
from flask import Flask, jsonify 
app = Flask(__name__) 
@app.route("/") 
def home():    
  return "Hello Students! Kubernetes CI/CD is working!" 
@app.route("/health") 
def health():
  return jsonify(status="healthy"), 200 

if __name__ == "__main__":    
  app.run(host="0.0.0.0", port=5000)

Create test_app.py 
from app import app 
def test_home_page():    
  client = app.test_client()    
  response = client.get("/")    
  assert response.status_code == 200    
  assert b"Kubernetes CI/CD is working" in response.data 

def test_health_endpoint():    
  client = app.test_client()    
  response = client.get("/health")    
  assert response.status_code == 200    
  assert response.json["status"] == "healthy"

1. Install the packages: .\.venv\Scripts\python.exe -m pip install -r requirements.txt 
2. Run the automated tests: .\.venv\Scripts\python.exe -m pytest -v Expected result: both tests pass. If a test fails, read the error message and check app.py and test_app.py. 
3. Start the Flask application: .\.venv\Scripts\python.exe app.py Keep this terminal open while testing. Open these addresses in a browser: Home page:     http://127.0.0.1:5000/ Health check:   http://127.0.0.1:5000/health


Dockerfile 

FROM python:3.12-slim 

WORKDIR /app COPY requirements.txt . 
RUN pip install --no-cache-dir -r requirements.txt 
COPY app.py . 
EXPOSE 5000 
CMD ["python", "app.py"]

.github/workflows/pipeline.yml 
name: Student Kubernetes CI/CD 
on:  
  push:    
    branches: [main]  
  pull_request:    
    branches: [main] 
  
  permissions:  
    contents: read 
  jobs: 
    test:    
      name: Checkout and Test   
      runs-on: ubuntu-latest    
    
      steps:     
        - name: Checkout source code       
          uses: actions/checkout@v4     
        - name: Set up Python       
          uses: actions/setup-python@v5       
          with:          
            python-version: "3.12"     
        - name: Install dependencies        
          run: |          
              python -m pip install --upgrade pip          
              pip install -r requirements.txt      
        - name: Run automated tests       
          run: python -m pytest -v
